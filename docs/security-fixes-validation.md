# Security and correctness fixes: validation

Validated on Linux on 2026-10-05. All twelve findings from the project review
have corresponding fixes and regression coverage. The changes do not implement
end-to-end BPSec or certify the bundled third-party libraries.

## Findings and proof

| Review finding | Fix | Executable regression evidence |
| --- | --- | --- |
| 1. Invalid free on allocation failure | Recover the containing memory block before freeing it | `memory_regression`: zero-length input and failures at five allocation positions; zero outstanding allocations |
| 2. Competing TCPCL readers | One locked message dispatcher handles ACKs and incoming segments, with a bounded completed-bundle queue | `tcp_cla_regression`: 50 bidirectional transfers, each with concurrent send/receive tasks at both ends |
| 3. Ingress loop never exits on TCP errors | Continue the task loop only after success | `bpnode_ingress_regression`: actual task source returns after timeout, OS error, closed stream, and length error |
| 4. SIGPIPE terminates the process | Suppress SIGPIPE on socket writes and handle send errors | `tcp_cla_regression`: send to closed peer with default SIGPIPE disposition; process survives and socket closes |
| 5. Partial timeout loses framing | Close failed/incomplete sessions; preserve idle receive timeouts; use nonblocking I/O and operation deadlines | `tcp_cla_regression`: STCP header/body truncation and every incomplete prefix of a TCPCL segment |
| 6. ACK path traversal | Authenticate control records, validate unsigned IDs/session IDs, and delete only matching pending records | Python traversal/unknown-ACK tests leave an actual temporary victim file untouched; valid ACK releases only its pending record |
| 7. Reused AES-GCM keys/nonces | Generate per-run keys or retain a private key file; generate fresh random nonces | Python tests check key persistence, fresh keys, private file permissions, and different nonces across codec instances |
| 8. Unauthenticated metadata/control messages | Encrypt/authenticate the complete record; bind non-custody demos to a fresh run ID | Python tests flip every byte of bundle/EOF/ACK records, reject wrong keys and previous-run records |
| 9. Per-segment transfer limit | Enforce accumulated transfer size before reading another segment | `tcp_cla_regression`: reject two four-byte segments under a four-byte transfer limit |
| 10. Failed startup retains sockets | Close listener/socket after accept/handshake failure; reset negotiated state for reuse | `tcp_cla_regression`: accept timeout and malformed handshake permit subsequent listen; configured limits are restored |
| 11. Sink truncates on reconnect | Open without truncation, seek to end, serialize complete writes and close, complete short writes | `video_sink_regression`: actual sink source preserves two recording sessions and concurrent bundles using forced short writes |
| 12. Premature custody release | Persist chunks with file/directory synchronization before ACK; retain restart receipts; require complete segments; retry pending relay records | Python tests cover disk failure, restart after receiving the last part first, duplicate replay, lost ground ACK, and byte-for-byte CLI runs of all three demos |

`video_security_regression` contains ten Python test cases. The overall CTest
suite has ten entries: five original smoke tests, four C regression executables,
and the Python suite. All ten entries pass in both the normal and sanitizer
builds. The C regression sources are compiled from the changed implementation;
the BPNode tests stub framework and bundle-decoder boundaries, not the task/sink
functions under test.

## Reproduce

From the project root, with the existing BSL/BPLib dependencies built and the
Python packages in `client-test/requirements.txt` installed:

```sh
cmake -S integration -B /tmp/bpsec-fixes-build
cmake --build /tmp/bpsec-fixes-build -j4
ctest --test-dir /tmp/bpsec-fixes-build -V --timeout 60

cmake -S integration -B /tmp/bpsec-fixes-asan \
  -DCMAKE_C_FLAGS='-g -O1 -fsanitize=address,undefined -fno-omit-frame-pointer' \
  -DCMAKE_EXE_LINKER_FLAGS='-fsanitize=address,undefined'
cmake --build /tmp/bpsec-fixes-asan -j4
ASAN_OPTIONS=detect_leaks=1:halt_on_error=1 UBSAN_OPTIONS=halt_on_error=1 \
  ctest --test-dir /tmp/bpsec-fixes-asan -V --timeout 60

cmake --build cfs-build/native/default --target bpnode bplib -j4
```

For another cFS build location, pass `-DCFS_BUILD=/path/to/cfs-build`. The BPNode
regressions require its generated headers and Makefile compiler include list.
Without these files CMake omits those two entries. The production cFS module
build uses the checkout's existing C99 configuration and `-Werror`.

Verbose transcripts are generated by CTest in
`/tmp/bpsec-fixes-build/Testing/Temporary/LastTest.log` and
`/tmp/bpsec-fixes-asan/Testing/Temporary/LastTest.log`.
The socket tests must be run where local TCP/UDP/socketpair I/O is permitted;
the execution sandbox returned EPERM for `send()`, so validation used an approved
run outside that sandbox. Sanitizer validation also ran outside it, allowing
LeakSanitizer to operate.

## Compatibility and limits

- The demo wire format changed. Old unauthenticated spool files are rejected,
  not migrated or deleted. The new default is `relay-spool-v2`; retain its
  `demo.key` together with the spool. Ground retains `.custody` receipts for
  restart recovery and deduplication.
- Demo participants share the demo key and authenticate complete records. This
  is a trusted-participant simulation, not a BPSec security-transparent relay.
- TCPCL receive buffering is bounded to four completed bundles per connection;
  excess inbound work fails the session instead of growing memory indefinitely.
- BPNode retains each contact's synchronization object for the lifetime of its
  persistent tasks. Standalone callers should call `Destroy` only after all
  users have stopped; `Close` supports reconnect.
- The video sink appends to an existing recording. Rotate the output explicitly
  while contacts are stopped when starting a new recording.
- No Windows runtime, real Hardy/HDTN interop, hardware power-loss experiment,
  or complete flight-system deployment was tested. ASan/UBSan cover the rebuilt
  C targets; prebuilt BSL dependencies were not rebuilt with instrumentation.
